# A股公告看板（本地）

每个工作日自动读取沪深两市上市公司公告，按日期、行业、公告类型分类展示，只呈现**日期 + 公司 + 核心内容**，重要公告自动提取正文摘要。

## 快速开始

```bat
双击 启动看板.bat  → 选 [1] 启动看板 → 浏览器打开 http://127.0.0.1:8765
```

首次使用（已自动配置好依赖，一般无需执行）：

```bash
pip install -r requirements.txt          # 安装依赖
python build_industry.py                 # 生成行业映射表（申万一级）
python fetch.py                          # 首次抓取（自动补最近2天）
python server.py                         # 启动看板
```

## 工作方式

- **每天早上 8:00 自动抓取**（服务运行时生效）：断点续抓，自动补全上次抓取日到今天的所有公告——周一自动补上周五，长假后自动补全整个假期，不重复不遗漏
- **标题过滤**：例行公告（会议通知、投资者关系、募集资金理财等）只留标题；重要公告（业绩、增减持、回购、重组、合同、风险、分红等）自动下载原文 PDF 提取核心内容
- **行业分类**：申万一级行业（百度股市通数据）；东财接口在当前网络环境被封锁，脚本已内置替代方案，恢复后可切换
- **存储**：JSON 文件（`data/YYYY-MM-DD.json`），纯文本、git 友好，方便上传 GitHub

## 项目结构

```
公告读取/
├── 启动看板.bat       # 一键启动入口
├── config.py          # 配置（端口、定时时间、摘要长度）
├── fetch.py           # 抓取引擎（巨潮资讯 + PDF摘要 + 分类）
├── build_industry.py  # 生成行业映射表（新浪代码 + 百度行业）
├── server.py          # 看板服务（Flask + 每日8点定时 + 启动补抓）
├── update_industry.ps1  # 东财行业切换脚本（东财恢复后可用）
├── web/index.html     # 看板前端
├── industry_map.json  # 股票代码 -> 申万行业
├── data/              # 公告数据（按日期JSON）
└── requirements.txt
```

## 看板功能

- 按日期查看（下拉选择，含星期提示）
- 按行业筛选、按公告类型筛选（业绩预告/增减持/回购/重组等 19 类）
- 关键词搜索（公司名/标题）
- "只看重要"开关（默认开，例行公告灰显可切换）
- 重要公告展示"核心内容"摘要，可点击查看原文 PDF
- 右上角"立即抓取"按钮手动更新

## 数据源

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 公告列表/正文 | 巨潮资讯网（沪深交易所指定披露平台） | 免费公开接口，无需密钥 |
| 行业分类 | 百度股市通（申万一级） | 东财接口网络封锁时的替代，机构标准 |

## 定时任务说明

定时抓取由 `server.py` 内置调度器实现（每天 8:00，跳过周末），**需要看板服务处于运行状态**。如希望开机自启，可将 `启动看板.bat` 的快捷方式放入启动文件夹（Win+R 输入 `shell:startup`）。

## 上传 GitHub 提示

- `data/` 和 `industry_map.json` 为纯文本/JSON，可直接纳入 git 管理
- `temp_pdf/` 为临时目录（解析后自动清理），建议加入 `.gitignore`
- 不包含任何密钥或隐私数据
